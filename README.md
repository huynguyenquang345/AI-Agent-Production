
# AI Task Management & Recruitment Assistant

Hệ thống trợ lý ảo tự động hóa quy trình quản lý công việc và tra cứu tài liệu nội bộ dựa trên kiến trúc **Agentic AI** và **Advanced RAG**, vận hành hoàn toàn bằng mô hình local (**Ollama / Qwen 2.5**) nhằm đảm bảo bảo mật dữ liệu tuyệt đối.

## 📂 Cấu trúc Repository Chuẩn Sản phẩm

- `docs/`: Tài liệu phân tích nghiệp vụ (Pain points, Use cases), tài liệu thiết kế kiến trúc kỹ thuật và quy trình chuẩn tích hợp AI.
- `week_1/`: Module chuyên sâu về Data & Knowledge Engine (Xử lý tài liệu, Chunking tối ưu, Vector Indexing với Qdrant).
- `week_2/`: Module xây dựng Agent Core (LangGraph Multi-Agent, Tool Calling, Memory Persistence, Human-in-the-Loop).
